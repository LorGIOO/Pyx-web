Política de privacidadWeb y aplicación

Tus documentos son tuyos.

Ni esta web ni Pyx te piden una cuenta, ponen cookies o envían estadísticas de uso. Aquí está, punto por punto, lo poco que sale de tu equipo y por qué.

Última actualización: 16 de noviembre de 2026

  • Esta web no usa cookies, analítica ni recursos de terceros: las fuentes y las imágenes se sirven desde aquí. Solo recuerda en tu navegador el tema (claro u oscuro) si lo cambias.
  • Lo que escribes o pegas en las demostraciones se queda en tu navegador. No se envía a ningún sitio.
  • La aplicación Pyx no tiene telemetría, informes de errores automáticos ni cuentas. Tus documentos no salen de tu equipo.
  • Pyx se conecta a Internet solo para buscar actualizaciones, preparar Python o LaTeX cuando lo pides, instalar una librería que falta y, si tú lo configuras, revisar el texto con LanguageTool.

1. Quién está detrás

Pyx es un proyecto de software libre con licencia MIT, mantenido por LorGIOO en GitHub. Para cualquier duda sobre esta política, abre una incidencia en github.com/LorGIOO/Pyx/issues. Ten en cuenta que las incidencias de GitHub son públicas: no escribas en ellas datos personales que no quieras publicar.

2. Esta web

Alojamiento

La web está publicada con GitHub Pages, un servicio de GitHub, Inc. Como con cualquier página, al visitarla tu navegador se conecta a los servidores de GitHub y les envía tu dirección IP y datos técnicos de la petición (la página que pides, el navegador que usas). GitHub puede registrarlos por motivos de seguridad y funcionamiento, según su declaración de privacidad. Quien mantiene Pyx no recibe esos registros ni estadísticas de visitas.

Cookies y almacenamiento

La web no usa cookies. Si pulsas el botón de tema, guarda la palabra light o dark en el almacenamiento local de tu navegador, con la clave pyx-tema, para recordarlo en la siguiente visita. No sirve para identificarte y no sale de tu navegador. Puedes borrarla cuando quieras borrando los datos de este sitio en tu navegador.

Terceros

Al cargar la web no se contacta con ningún otro servicio: no hay analítica, publicidad, vídeos incrustados ni fuentes externas. Los enlaces de descarga, del código fuente y de las incidencias llevan a github.com, que tiene su propia política.

Las demostraciones

El laboratorio, el corrector, el autocompletado, el pegado de tablas y las anotaciones funcionan enteros en tu navegador, con JavaScript. Lo que escribes, pegas o dibujas no se guarda ni se envía, y desaparece al cerrar la página.

3. La aplicación Pyx

Pyx funciona sin conexión. No pide registro, no envía estadísticas de uso ni informes de errores, y no lee ni sube tus documentos. Lo que escribes, tus datos y tus resultados se quedan en las carpetas de tus proyectos y en la carpeta de datos de Pyx en tu equipo: %LOCALAPPDATA%\com.pyx.studio en Windows y ~/.local/share/pyx en Linux. Al desinstalar Pyx, el desinstalador ofrece borrar esa carpeta.

4. Tus derechos

Quien mantiene Pyx no recoge ni guarda datos personales de quienes visitan la web o usan la aplicación, así que no tiene datos tuyos que consultar, corregir o borrar. Sobre los datos técnicos que GitHub registra al servir la web o las descargas, puedes ejercer tus derechos ante GitHub, como explica su declaración de privacidad. Si crees que algo no se ajusta a la normativa de protección de datos, también puedes acudir a la autoridad de control de tu país (en España, la Agencia Española de Protección de Datos).

5. Cambios en esta política

Si una versión de Pyx o de la web cambia algo de lo anterior (por ejemplo, una conexión nueva), esta página se actualizará antes y lo dirá en sus novedades. La fecha de arriba indica la última revisión.
