Projects to open, compile and copy.

Complete Pyx projects with made-up data. Download one, open it and compile it as it is; then change a datum and watch the whole document rebuild itself. Copy them, break them, use them as templates.

  1. Download the .zip and unzip it wherever you like.
  2. Open in Pyx the main file each one names.
  3. Compile with Compile & view (Ctrl+Shift+B). The libraries they use come with the Python Pyx sets up.

00

Empty template

The starting point for a new piece of work.

  • .pltx preamble
  • .sty style
  • subdocuments

The same structure as the calculation report, without content: a main document that only gathers chapters, a .sty file with the whole look (margins, colours, cover, \pass and \fail) and a resources folder for images, data and calculations.

  • _Preamble.pltx only has the cover, the table of contents and one \input per chapter.
  • Each chapter is a separate .pltx, with its own Python cells.
  • pyxstyle.sty keeps the style: change it once and the whole document changes.

01

Calculation report

A fictitious footbridge, from the input data to the conclusions.

  • chapters
  • CSV and Excel
  • handcalcs
  • pint
  • plots
  • \pyif
  • Jupyter

A large piece of work organised as it would be in real life. The data is read from a CSV and an Excel file; the beam is designed with handcalcs, which writes every formula with its values, and with pint for units; the text says «PASSES» or «FAILS» depending on the result. The wind annex has no cells: it calls the functions of a Jupyter notebook.

  • The variables of one chapter are used in the following ones.
  • One table with a \py{} in each cell and another written whole with tabletex.
  • A table whose rows a loop writes, comparing three sections.
  • Change section = "IPE 330" to "IPE 300" and watch the text, the plot and the tables change.

02

Handcalcs and units

Hand calculations, without writing them by hand.

  • handcalcs
  • pint
  • \pyif
  • plots

A single file with the most striking side of Pyx for a technical calculation: a footing and a column. %%render cells put the full development of each formula in the PDF; %%render params writes the data in columns. Every quantity carries its units and conversions happen by themselves.

  • Greek letters and subscripts from the names: lamb_r is written λr.
  • \pyif compares kPa with MPa without manual conversions.
  • A buckling curve with the column's point and a summary table.

03

Only a Jupyter notebook

A report without a single cell: all the calculation lives in the notebook.

  • \pynotebook
  • \pyfile
  • .ipynb
  • .py with # %%
  • pandas
  • \pyif

For whoever already calculates in Jupyter or VS Code. The document links a notebook (\pynotebook) and a script with # %% blocks (\pyfile) and, from there, uses their variables and calls their functions with the arguments it wants. The plot is saved by the notebook and the document includes it with \includegraphics.

  • A whole table written by a function of the notebook: \py{period_rows([2, 5, 10])}.
  • A pandas table queried cell by cell: \py{quantiles.loc[100, 'P']}.
  • If the notebook is open and run, Pyx copies its values without running anything.

04

Tables, plots and conditionals

A normal DataFrame and a document that asks it questions.

  • pandas
  • tabletex
  • loops
  • matplotlib
  • \pyif
  • cells

Fictitious energy data in a pandas DataFrame with nothing prepared for LaTeX. The first table is written in LaTeX and the document asks for each number: \py{df.at["Jan", "total"]}. The second is the same DataFrame in one line with tabletex, and the third is written by a loop.

  • Two ways to place a plot: figtex() (the whole figure) and figure() + \includegraphics.
  • Sentences that change with the data, with colours and even the plural: «1 month» or «4 months».
  • Change a datum of the DataFrame: tables, plots and sentences change at once.

05

Excel and CSV data

A budget whose numbers live in Excel, without a line of Python.

  • \hoja
  • \celda
  • .xlsx
  • .csv
  • no Python

The document links an Excel workbook with \hoja[Quantities]{data/works.xlsx} and places its cells with \celda{E4}, or a whole range with \celda{A2:E7}, which comes out as the body of a table. A chapter reads a CSV with the ; and decimal comma of Excel in many European languages. Change a number in Excel, save and compile: the document changes by itself.

  • A single cell in a sentence: \celda{B3}; another sheet: \celda{Summary!B5}.
  • A whole table from Excel: header \celda{A1:E1} and body \celda{A2:E7}.
  • \celda[T]{B2:B6} places a column as a row (and the other way round).
  • It reads what Excel saved, including the results of formulas.
