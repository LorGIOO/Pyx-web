Code signing

Who signs Pyx’s Windows installers, how they are built and what each version is checked for before it is published.

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

What is signed

The Windows release artifacts of Pyx, an open source (MIT) desktop LaTeX editor with embedded Python cells:

  • the NSIS installer Pyx_<version>_x64-setup.exe,
  • the MSI installer Pyx_<version>_x64_en-US.msi,
  • the application executable pyx.exe contained in them.

Only binaries built from the source code of the LorGIOO/Pyx repository are signed. Every release is built by GitHub Actions (release.yml) from a version tag, on GitHub-hosted runners, with a pinned Rust toolchain. No binary built on a personal computer is ever signed. Before each release is published, its installers are scanned with antivirus software.

Pyx does not bundle third-party executables. When the user asks for it in the “Prepare Pyx” dialog, Pyx downloads uv, a standalone Python and Tectonic from their official GitHub releases into its own data folder; those files keep their publishers’ own signatures (or lack of them) and are not signed under this policy.

Changes from outside contributors are only merged through pull requests reviewed by a committer. Every signing request is approved manually by an approver. All team members use multi-factor authentication on GitHub and SignPath.

Privacy policy

Pyx has no telemetry, no crash reporting and no user accounts, and it never uploads the user’s documents. It connects to other networked systems only in these cases:

  • Update check: a few seconds after start-up, and when the user clicks “Check for updates”, Pyx asks api.github.com for the latest published release. If the user installs it, the installer is downloaded from github.com and verified with its SHA-256 hash.
  • Setup, on request: when the user clicks “Prepare”, Pyx downloads uv, a standalone Python and Tectonic from GitHub and Python packages from PyPI; Tectonic downloads the LaTeX packages a document needs the first time it compiles it.
  • Installing a missing package, on request: the package name is sent to PyPI.
  • LanguageTool, only if configured by the user: the document text is sent to the server the user enters (their own server, or the public one at api.languagetool.org).

The full privacy policy is at lorgioo.github.io/Pyx-web/en/privacy/.
