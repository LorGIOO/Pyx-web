Proyectos para abrir, compilar y copiar.

Proyectos completos de Pyx con datos inventados. Descarga uno, ábrelo y compílalo tal cual; luego cambia un dato y mira cómo se rehace el documento entero. Cópialos, rómpelos, úsalos de plantilla.

  2. Abre en Pyx el archivo principal que se indica en cada uno.
  3. Compila con Compilar y ver (Ctrl+Mayús+B). Las librerías que usan las trae el Python que prepara Pyx.

00

Plantilla vacía

El punto de partida para un trabajo nuevo.

  • preámbulo .pltx
  • estilo .sty
  • subdocumentos

La misma estructura que la memoria de cálculo, sin contenido: un documento principal que solo reúne capítulos, un archivo .sty con todo el aspecto (márgenes, colores, portada, \cumple y \nocumple) y una carpeta de recursos para imágenes, datos y cálculos.

  • _Preámbulo.pltx solo tiene la portada, el índice y un \input por capítulo.
  • Cada capítulo es un .pltx aparte, con sus propias celdas de Python.
  • memoria.sty guarda el estilo: cámbialo una vez y cambia todo el documento.

01

Memoria de cálculo

Una pasarela peatonal ficticia, de los datos a las conclusiones.

  • capítulos
  • CSV y Excel
  • handcalcs
  • pint
  • gráficas
  • \pyif
  • Jupyter

Un trabajo grande organizado como se haría en la vida real. Los datos se leen de un CSV y de un Excel; la viga se calcula con handcalcs, que escribe cada fórmula con sus valores, y con pint para las unidades; el texto dice «CUMPLE» o «NO CUMPLE» según el resultado. El anejo de viento no tiene celdas: llama a las funciones de un cuaderno de Jupyter.

  • Las variables de un capítulo se usan en los siguientes.
  • Una tabla con un \py{} en cada celda y otra entera con tabletex.
  • Una tabla cuyas filas escribe un bucle, comparando tres perfiles.
  • Cambia perfil = "IPE 330" por "IPE 300" y mira cómo cambian el texto, la gráfica y las tablas.

02

Handcalcs y unidades

Cálculos a mano, sin escribirlos a mano.

  • handcalcs
  • pint
  • \pyif
  • gráficas

Un solo archivo con lo más vistoso para un cálculo técnico: una zapata y un pilar. Las celdas %%render ponen en el PDF el desarrollo completo de cada fórmula; %%render params escribe los datos en columnas. Cada magnitud lleva sus unidades y las conversiones se hacen solas.

  • Letras griegas y subíndices a partir de los nombres: lamb_r se escribe λr.
  • \pyif compara kPa con MPa sin conversiones a mano.
  • Una curva de pandeo con el punto del pilar y una tabla resumen.

03

Solo un cuaderno de Jupyter

Un informe sin ninguna celda: todo el cálculo vive en el cuaderno.

  • \pynotebook
  • \pyfile
  • .ipynb
  • .py con # %%
  • pandas
  • \pyif

Para quien ya calcula en Jupyter o en VS Code. El documento vincula un cuaderno (\pynotebook) y un script con bloques # %% (\pyfile) y, a partir de ahí, usa sus variables y llama a sus funciones con los argumentos que quiere. La gráfica la guarda el cuaderno y el documento la incluye con \includegraphics.

  • Una tabla entera escrita por una función del cuaderno: \py{filas_periodos([2, 5, 10])}.
  • Una tabla de pandas consultada celda a celda: \py{cuantiles.loc[100, 'P']}.
  • Si el cuaderno está abierto y ejecutado, Pyx copia sus valores sin ejecutar nada.

04

Tablas, gráficas y condicionales

Un DataFrame normal y un documento que le pregunta.

  • pandas
  • tabletex
  • bucles
  • matplotlib
  • \pyif
  • celdas

Datos ficticios de consumo energético en un DataFrame de pandas sin nada preparado para LaTeX. La primera tabla se escribe en LaTeX y cada número lo pide el documento: \py{df.at["Ene", "total"]}. La segunda es el mismo DataFrame en una línea con tabletex, y la tercera la escribe un bucle.

  • Dos formas de llevar una gráfica: figtex() (la figura entera) y figure() + \includegraphics.
  • Frases que cambian con los datos, con colores y hasta el plural: «1 mes» o «4 meses».
  • Cambia un dato del DataFrame: tablas, gráficas y frases cambian a la vez.

05

Datos de Excel y CSV

Un presupuesto cuyos números viven en Excel, sin una línea de Python.

  • \hoja
  • \celda
  • .xlsx
  • .csv
  • sin Python

El documento vincula un libro de Excel con \hoja[Mediciones]{datos/obra.xlsx} y coloca sus celdas con \celda{E4} o un rango entero con \celda{A2:E7}, que sale como el cuerpo de una tabla. Un capítulo lee un CSV con el ; y la coma decimal del Excel en español. Cambia un número en Excel, guarda y compila: el documento cambia solo.

  • Una celda suelta en una frase: \celda{B3}; otra hoja: \celda{Resumen!B5}.
  • Una tabla entera desde Excel: cabecera \celda{A1:E1} y cuerpo \celda{A2:E7}.
  • \celda[T]{B2:B6} pone una columna como fila (y al revés).
  • Lee lo que Excel guardó, también los resultados de las fórmulas.
